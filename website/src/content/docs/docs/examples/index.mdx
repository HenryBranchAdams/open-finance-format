## Apple DCF

The [Apple DCF example](/docs/examples/apple-dcf/) applies the Public Equity
Research profile to a real formula-driven workbook. It binds source facts,
analyst assumptions, scenario outputs, the workbook digest, author-declared
lineage, and freshness.

Its valuation is illustrative, not investment advice. Package conformance does
not establish that the assumptions are correct or that another implementation
can execute the workbook identically.

## Conformance fixtures

The repository also contains a finance-agnostic minimal Core package, a
synthetic traceable Public Equity package, and focused invalid fixtures. Those
fixtures prove bounded reference behavior; they are not an adoption claim.
