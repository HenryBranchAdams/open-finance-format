OFF keeps four evidence layers separate:

1. **Normative semantics** define what conforming packages and evaluators mean.
2. **Offline corpus behavior** checks the reference evaluator against fixed,
   reviewed cases.
3. **Mechanical release closure** binds a candidate's public artifacts and
   checksums.
4. **Clean-room evidence** tests whether unaffiliated implementers can consume
   and produce packages from public materials alone.

The first three cannot substitute for the fourth.
