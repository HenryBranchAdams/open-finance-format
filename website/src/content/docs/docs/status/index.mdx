## Current release line

OFF v0.1-rc.1 includes:

- two normative profiles: Core and Public Equity Research;
- JSON Schemas and a stable rule registry;
- an offline TypeScript reference evaluator;
- deterministic normalization, diagnostics, lineage, and freshness;
- a layered conformance corpus; and
- public clean-room consumer and producer tasks.

## Pending

Promotion remains blocked on independently reviewed consumer, producer, and
first-time-author evidence. Adoption, financial correctness, and independent
lineage review are not claimed.

## Outside the current boundary

OFF is not a spreadsheet runtime, social network, brokerage interface,
investment recommender, or universal formula language.

Continue with the [product boundary](/docs/status/product-boundary/) and
[roadmap](/docs/status/roadmap/).
